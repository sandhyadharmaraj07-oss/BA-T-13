# Superstore Business Intelligence & Performance Analysis

## Project Overview
This project analyzes the Sample Superstore dataset using Tableau Public to identify business trends, sales performance, profitability, and regional comparisons.

## Objective
To explore business data, create interactive visualizations, identify meaningful insights, and provide recommendations for improving business performance.

## Tools Used
- Tableau Public
- Microsoft Excel / CSV
- GitHub

## Visualizations
1. Total Sales KPI
2. Total Profit KPI
3. Total Orders KPI
4. Total Quantity KPI
5. Monthly Sales Trend
6. Category Sales Analysis
7. Sub-Category Profit Analysis
8. Regional Performance Analysis
9. State-wise Sales Map
10. Sales vs Profit Scatter Plot

## Interactive Features
- Year filter
- Region filter
- Category filter
- Interactive dashboard exploration

## Key Findings
- Total Sales: $2,297,200.86
- Total Profit: $286,397.02
- Total Orders: 5,009
- Total Quantity Sold: 37,873
- Technology recorded the highest category sales.
- West recorded the highest regional sales.
- Some sub-categories and orders showed low or negative profits.

## Recommendations
- Improve profitability of low-performing products.
- Review discount strategies.
- Strengthen sales in lower-performing regions.
- Focus on high-performing product categories.
- Use data-driven planning to improve business decisions.
